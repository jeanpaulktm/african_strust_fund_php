🎯 ENDPOINTS API - VUE D'ENSEMBLE

┌─ 🔐 AUTHENTIFICATION (sans token)
│
├─ POST   /auth/login              → Connexion client
├─ POST   /auth/register           → Inscription client
├─ POST   /auth/logout             → Déconnexion
├─ POST   /auth/refresh            → Renouveler token
└─ GET    /auth/profile            → Profil utilisateur

┌─ 📊 DASHBOARD (avec token)
│
└─ GET    /dashboard               → Synthèse complète

┌─ 💰 PRÊTS (avec token)
│
├─ GET    /prets                   → Liste paginée (filtrable)
├─ GET    /prets/{id}              → Détails complets + échéances
├─ POST   /prets                   → Créer une demande
└─ POST   /prets/{id}/rembourser   → Rembourser

┌─ 💸 TRANSACTIONS (avec token)
│
├─ GET    /transactions            → Liste paginée (filtrable)
├─ GET    /transactions/{id}       → Détails
├─ POST   /transactions/depot      → Faire un dépôt
├─ POST   /transactions/retrait    → Faire un retrait
└─ POST   /transactions/virement   → Faire un virement

┌─ 📈 PLACEMENTS (avec token)
│
├─ GET    /placements              → Liste paginée (filtrable)
├─ GET    /placements/{id}         → Détails complets
├─ POST   /placements              → Créer un placement
└─ POST   /placements/{id}/retirer → Retirer (partiel/total)

┌─ 👤 PROFIL (avec token)
│
├─ GET    /profil                  → Récupérer profil
├─ PUT    /profil                  → Mettre à jour profil
└─ POST   /profil/avatar           → Upload avatar

🔐 AUTHENTIFICATION

1️⃣  Login
   POST /auth/login
   Body: { "telephone": "+243900000000", "password": "pwd" }
   → Retourne le token et les soldes

2️⃣  Register
   POST /auth/register
   Body: { "prenom", "nom", "telephone", "email", "password" }
   → Crée le compte et retourne le token

3️⃣  Token Bearer
   Header: Authorization: Bearer {token}
   → Utilisé pour toutes les requêtes authentifiées

4️⃣  Refresh
   POST /auth/refresh (avec token)
   → Retourne un nouveau token

💡 EXEMPLES D'UTILISATION - FLUTTER/DART

Installation:
1. Ajouter les dépendances (dio, provider, json_serializable, etc.)
2. Créer ApiService pour gérer les requêtes
3. Créer AuthService pour l'authentification
4. Utiliser ChangeNotifierProvider pour l'état

Login:
```dart
final apiService = ApiService();
final response = await apiService.post(
  '/auth/login',
  data: {
    'telephone': '+243900000000',
    'password': 'password123'
  },
);
final token = response['token'];
apiService.setAuthToken(token);
```

Dashboard:
```dart
final response = await apiService.get('/dashboard');
final soldes = response['soldes'];
final prets = response['prets'];
final placements = response['placements'];
```

Créer un prêt:
```dart
final response = await apiService.post(
  '/prets',
  data: {
    'montant': 200000,
    'duree_mois': 24,
    'id_produit': 1
  },
);
```


⚙️ CONFIGURATION

Fichier: api/v1/config.php

Constantes:
- API_VERSION = '1.0.0'
- API_NAME = 'African Trust Fund Mobile API'
- API_TIMEOUT = 30 secondes

CORS:
- Permet les requêtes de n'importe quelle origine
- Support des headers personnalisés
- Méthodes: GET, POST, PUT, DELETE, PATCH, OPTIONS

Authentication:
- Token Bearer avec signature HMAC-SHA256
- Durée: 86400 secondes (24 heures)
- Clé secrète: $CIPHER_KEY ou default
